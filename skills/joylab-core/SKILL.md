# JoyLab Core Skill V1.0

## Purpose
Provide a portable baseline for JoyLab work across ChatGPT, Codex, Claude, Gemini, local agents, and future tools.

## Brand operating idea
Think → Experiment → Grow

## Core reasoning flow
Question → Evidence → Insight → Action

## JOYLAB 7 editorial/research flow
1. HOOK — frame the question or tension.
2. FACT — separate verified facts from claims and assumptions.
3. WHY — explain causes and relevant context.
4. TRANSMISSION — show how effects travel through a system, industry, team, customer, or portfolio.
5. JUDGMENT — state the JoyLab interpretation with evidence.
6. SCENARIO — present conditions and alternative outcomes instead of one-point prophecy.
7. NEXT — define the next observation, action, or decision checkpoint.

## Default pillars
- INVEST: markets, companies, ETFs, portfolio, investment philosophy.
- AI: models, agents, tools, industry, automation.
- WORK: leadership, customer service operations, KPI, coaching, project management, culture.
- BOOKS: reviews, reading lists, ideas worth retaining.
- BUILD: apps, automations, experiments, development logs, operating systems.

## Durable-output standard
A substantial output should, where relevant, include:
- Objective and scope
- Verified facts / evidence
- Assumptions
- Decision or recommendation
- Execution steps
- Success metrics or acceptance criteria
- Risks / blockers
- Next checkpoint
- Related knowledge or internal-link candidates

## Project execution standard
Prefer small verified increments over large rewrites.
Default lifecycle:
SPEC → PLAN → IMPLEMENT → TEST → REVIEW → REGRESSION → RELEASE GATE

Status vocabulary:
- PASS: acceptance criteria are met with evidence.
- BLOCKED: a named blocker prevents completion.
Do not label partially verified work as complete.

## Content asset rule
Do not optimize only for one-off posts. Convert useful material into reusable knowledge nodes, series, templates, Gold Cases, schemas, or decision records whenever the value is durable.

## Truth rule
Do not invent unavailable facts. Mark estimates, interpretations, and unresolved points explicitly. For current public facts, verify using current sources when material.

## Cross-agent portability
When starting in a new environment, load this file plus `records/BASELINE.md` and relevant entries from `records/DECISIONS.md`. Then load the target project's local instructions.

## Privacy boundary
This global skill must remain safe to reuse broadly. Do not store customer-level data, secrets, credentials, restricted corporate details, or sensitive personal data here.
