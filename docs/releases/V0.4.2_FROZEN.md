## Why this baseline exists

V0.4.2 is the first point where JoyLab Agent OS can prove not only that a skill exists, but how it came to exist.

The baseline closes the governed-learning lineage:

```text
Core8 Decision
  -> Experience
  -> Evidence Snapshot / EVS
  -> Skill Candidate
  -> Approval Audit
  -> Certified Skill
```

This is the boundary between "agent memory" and "auditable agent learning".

## Frozen invariants

1. AI may propose a skill change, but cannot modify a CERTIFIED skill in place.
2. Evidence must be attributable and immutable once sealed.
3. Approval must be attributable to an actor and reason.
4. Missing required provenance makes certification lineage incomplete.
5. A ranking or event signal never becomes an automatic investment action.
6. Human approval remains a final governance boundary for critical decisions.
